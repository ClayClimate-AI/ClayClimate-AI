## ![My Projects](https://readme-typing-svg.demolab.com?font=Fira+Code&weight=600&size=24&duration=2000&pause=1000&color=58A6FF&width=240&height=36&repeat=false&lines=My+Projects)

Here are some of the public projects I've been working on:

- [HVAC Failure Prediction](https://neural-network-preditctions.netlify.app): An interactive neural network simulation that predicts whether a commercial rooftop unit will fail within 30 days, visualizing forward propagation and backpropagation. Built with Three.js and GSAP.
- [hvac-checklist-tool](https://github.com/ClayClimate-AI/hvac-checklist-tool): A checklist app for HVAC technicians to confirm tools and parts before leaving for a job site, reducing wasted trips caused by work orders that don't match on-site conditions.
- [HVAC Job Finder](https://hvac-job-finder.netlify.app): A job search dashboard that filters Houston-area HVAC listings by role, including controls/BAS, technician, apprentice, and refrigeration.
- [cg-rendering-timeline](https://github.com/ClayClimate-AI/cg-rendering-timeline) ([live demo](https://cg-timeline-evolution.netlify.app)): An interactive 3D timeline of computer graphics history, from Sketchpad in 1963 to real-time ray tracing, built with React, Three.js (React Three Fiber), Framer Motion, Vite, and Tailwind CSS.
- [ML Roadmap Knowledge Graph](https://ml-graphical-roadmap.netlify.app): An interactive 3D graph mapping how core machine learning concepts, algorithms, and tools connect.
- [Freelance Client Portfolio](https://portfolio-joseph-russel.netlify.app): A portfolio website designed and deployed for a client to showcase his professional work.
- ITAI-1371 Machine Learning labs: [ML dev tools](https://github.com/ClayClimate-AI/ITAI1371-L02-ML-Dev-Tools), [ML workflow](https://github.com/ClayClimate-AI/itai-1371-module-03-ml-workflow), [EDA](https://github.com/ClayClimate-AI/itai-1371-module-04-eda): pandas, NumPy, and matplotlib work, from exploratory analysis through model training and evaluation.
- [ITAI_ML_FirstRepo_Turing_Collective](https://github.com/ClayClimate-AI/ITAI_ML_FirstRepo_Turing_Collective): A team Git workflow project demonstrating branch management, pull request review, and contribution documentation.
- [ITAI-1370-history-theory](https://github.com/ClayClimate-AI/ITAI-1370-history-theory): Sixteen modules of AI history and theory, from symbolic logic through deep learning, NLP, computer vision, and robotics.
- [Earlier front-end work](https://github.com/josephc1417): React, Vite, and Tailwind applications built and deployed in 2023–2024.
